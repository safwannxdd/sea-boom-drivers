Takeoff coding sheet 2 (18 charts)

Your code marks only when a takeoff STARTED. Whether it lasted or crashed is classified afterwards by separate rules.

• Rise lasting 2+ years, even if it then crashes → mark the year the rise began (the crash is classified as a spike or slowdown automatically).
• A one-year blip that falls straight back → no takeoff.
• Bumpy but trending up → mark where the upward trend begins.
• Already rising at Y1 → already taken off before Y1.
